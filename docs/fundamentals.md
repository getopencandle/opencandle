# Reported fundamentals

The Company fundamentals dialog reads SEC companyfacts JSON through an optional public request or local file/paste. It works with a user-supplied CIK and does not connect to an account. The request sends the CIK, declared application User-Agent and ordinary network connection metadata to data.sec.gov. No request runs on launch. Saved data stays inside the local workspace and is included in export/reset.

GME and SPY CIK suggestions come from SEC filing indexes, not ticker inference: [GameStop, CIK1326380](https://www.sec.gov/Archives/edgar/data/1326380/000132638026000013/0001326380-26-000013-index.htm) and [SPDR S&P500 ETF Trust, CIK884394](https://www.sec.gov/Archives/edgar/data/884394/000119312524149097/0001193125-24-149097-index.htm), checked2026-10-14. A filing entity can lack companyfacts coverage. Any positive CIK of up to ten digits can be requested. The selected company is identified independently of the chart ticker and prices.

The browser exposes the response's complete supported concept collection, with taxonomy/tag, supplied label/definition, exact unit, period start/end, value, filing date, form, accession and fiscal metadata. Null or missing descriptive labels fall back to the visible taxonomy tag. Unknown fiscal metadata stays null. The raw concept view preserves reported values. Statement views use reported standalone quarters and compute explicitly disclosed eligible TTM periods and six supported ratios/cash-flow measures from reported inputs. They do not derive standalone quarters by subtracting year-to-date totals. They preserve filing cutoffs, currencies and missing values; balance-sheet stocks are not summed as flows. These local methods are not a claim of vendor-standardized parity.

The filing cutoff is inclusive at calendar-day precision. A filed date does not identify the time when a filing became available intraday. These facts must not be used as proof of intraday strategy information availability. Original/latest selections compare filing days within the same tag, unit and start/end period. Unknown filing dates are excluded with an explicit count when a cutoff is present; with no cutoff they remain visible as unordered observations. Different values on the same filing day remain conflicting rows. Changes across filing days remain revision history. Equal values with different accession/form metadata stay separate. Only complete identical observations are counted together.

Duration filters are explicit OpenCandle rules:60–120 days,300–400 days, other durations, instant, or all. They are not claims of the issuer's exact fiscal quarter/year classification. Supplied fiscal labels remain separate columns. The table displays up to2,000 rows; export includes every selected result with source kind, URL and retrieval time. Formula-like string cells are escaped for spreadsheet import.

The parser bounds concepts and observations, rejects invalid dates, nonfinite values and integers that JavaScript cannot represent exactly. Local import is capped at20MiB. The desktop provider has its own32MiB decoded-response limit. Workspace storage has a separate32MiB cap; an oversized save reports an error and preserves the prior saved document.

## Offline synthetic companyfacts

Use examples/companyfacts-LVDEMO-synthetic.json for a small offline exercise. Open Company fundamentals, expand Load SEC data or import a local file, check Synthetic fixture data, then choose Import JSON file or paste that file into Companyfacts JSON and choose Import pasted JSON. The example is 2.2 KB and contains an invented entity and four invented FY2023 values: revenue1000, cost600, gross profit400 and net income100. Its numeric CIK and accession are format identifiers only. They are not a reserved identity or evidence of a real filing, and importing the example sends no request.

The synthetic notice remains visible across all statement and facts tabs. With Statement scale set to units, the income statement shows the four literal values. Statistics can derive gross margin40% and net margin10%. Other fields stay unavailable. The import checkbox applies to the next local import and is unchecked when the dialog is reopened; saved documents keep their own source kind. Ordinary local imports remain explicitly unverified, and optional SEC fetching always retains SEC provenance.

To show this fixture in symbol details, select a SYNTHETIC DEMO chart and explicitly choose Use for that symbol after importing. No automatic company/ticker link is created. Synthetic facts cannot link to a real-market symbol. CSV files keep source_kind=synthetic and use an OpenCandle synthetic (LV-SYNTHETIC) filename. This source change still requires the recorded model/handler regressions and packaged interface checks; consult the current state report before claiming verification.

## Evidence and gaps

Independent desktop and analysis reviews found and repaired unknown filing chronology loss, misclassified revision history, lost accession metadata, ambiguous concept identifiers, nullable metadata rejection and a late fetch restoring removed data. Regression tests are in tests/fundamentals and tests/ui/workspace-validation.test.ts. A live GME retrieval (2026-10-14) parsed 510 concepts and 23,663 observations and preserved 62 unknown fiscal-year/period pairs.

The live parser integration does not certify every financial definition, correspondence with field definitions used elsewhere, point-in-time data completeness or packaged UI behavior. SEC aggregates eligible entity-wide standard-taxonomy facts; this does not reproduce all custom/disaggregated filing facts, ETF holdings, financial ratios, forecasts or market prices. Full fundamentals parity remains incomplete. See [SEC API coverage](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) and docs/provider-sec.md.
