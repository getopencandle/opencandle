# OpenCandle portable workspace

Extract the complete folder and run `OpenCandle.exe`. No development tools or checkout are needed. Keep the executable, resources, locales and other supplied files together. This is an unsigned Windows x64 build, so Windows SmartScreen may ask you to confirm. A new install opens on a live BTC-USD chart from Coinbase public data (no account or key). If Coinbase cannot be reached it shows example data with **Try live again**. Keep sandboxing enabled and do not weaken OS or profile permissions to work around a startup error.

The built-in GME, SPY and other example symbols use **synthetic demonstration data**, not actual market prices. Paper-trading balances, fees and orders are virtual. There is no OpenCandle account login, real order execution, funding, payment, OpenCandle telemetry or hosted workspace storage. Optional market-data connections are separate: the Data sources page lists what each kind of data needs at minimum (nothing for crypto, economic data and SEC filings; a free Alpaca account and key for real-time US stocks) and where your settings are saved. Saved Alpaca credentials are encrypted by the main process and are excluded from workspace exports. Provider availability, entitlements and data-use terms apply.

1. Use the symbol control to pick a symbol. BTC-USD is live from Coinbase; the other built-in symbols are synthetic examples. A watchlist click selects details and opens its exact bound source in the active chart after a local 300 ms delay; double-click requests all charts. Enter or Open chart opens explicitly. Modified clicks select without opening. The local delay can differ from Windows preferences; a later double-click can follow an already accepted single-click change. [Watchlist instructions](docs/watchlist-import.md) explain multiple lists, source selection and TXT/JSON import. [Advanced analysis instructions](docs/watchlist-advanced-import.md) explain supplied observations, calendar/news associations and the [synthetic example](examples/watchlist-advanced-synthetic.json). Local symbol notes stay on this computer and are included in workspace/watchlist JSON exports.
2. Open Chart settings to choose a theme and chart colors, or choose indicators and drawing tools. Apply/Cancel controls govern each draft. The top layout name opens saved local layouts, including create, copy, rename, favorites, autosave and portable JSON import/export. [Saved-layout instructions](docs/layout-library.md) explain saved snapshots, recovery drafts and source requirements.
3. Import your own local OHLCV using `time,open,high,low,close,volume`. Review timestamp units, instrument settings and parsing diagnostics. Use Data sources settings to turn live market data on or off (Coinbase public data is on for a new install); imported, synthetic, cached and live data retain separate provenance.
4. Open News and filings, import [examples/news-synthetic.json](examples/news-synthetic.json), and exercise its visibly synthetic GME/SPY filters. [News import instructions](docs/news-import.md) explain the JSON schema, saved flows and cancellation.
5. Open Script editor and run a shipped CandleScript example. [CandleScript API](docs/candlescript.md) describes `init`/`onBar`, plotting, state, virtual proposals and limits. Full Pine compatibility is not provided.
6. For offline fundamentals, open **Fundamentals**, expand the import controls, check **Synthetic fixture data**, and import [examples/companyfacts-LVDEMO-synthetic.json](examples/companyfacts-LVDEMO-synthetic.json). Its invented company has revenue 1,000, gross profit 400 and net income 100 for 2023. It is not GME or SPY company data. [Fundamentals instructions](docs/fundamentals.md) explain statement views, provenance and explicit symbol links. Optional Fundamentals and SEC filings actions fetch a user-supplied CIK from the public SEC service without authentication. They send that public identifier and ordinary network metadata, not workspace contents. SEC facts and filings are separate from synthetic prices, breaking news and complete historical coverage. [SEC facts](docs/provider-sec.md) and [SEC filings](docs/provider-sec-submissions.md) describe the capabilities.
7. The interval menu supports exact supplied histories and explicitly selected UTC aggregation. Derived data retains its source and unknown historical availability; exchange-session alignment is not guaranteed. Local alerts use actual observation time and disclose historical snapshot limits. Local alerts run while the app is running; unsupported background sources are refused explicitly. A live forming bar is excluded from completed-bar evaluation, and replay uses its frozen history. Desktop notifications depend on OS permission. No hosted alert service or remote webhook delivery is connected.
8. Use Data sources > Saved on this computer to inspect the local folder, export the workspace, review a saved export for replacement, or explicitly reset it. Reset clears the active saved workspace and preserves revision metadata; exported files remain. JSON/CSV exports use native Save dialogs. See [workspace import and recovery](docs/workspace-import.md) for limits, cancellation and recovery gaps.

The folder includes application/third-party licenses, notices, SBOM and `build-manifest.json` with source/artifact hashes. When you report a problem, include the build ID and the error code shown. Do not retain diagnostic screenshots, video, image traces or private account material.

Startup diagnostics stay locally in `%APPDATA%\OpenCandle\startup-status.json` (or the explicitly selected local profile). This small file contains only the build identity, generated time, and the last 32 startup/process event codes. It contains no workspace contents, scripts, paths, account details or error stacks and is never uploaded. Close the app to copy or delete it. A new primary launch replaces the record; Local storage's workspace reset does not delete this separate diagnostic file. Very early native-process failures can happen before any record is written. The presence of `load-finished` means the document loaded, not that the workspace was visibly working.
