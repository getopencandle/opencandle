# Optional SEC company-facts capability

`fetchSecCompanyFacts({requestId,cik})` is an explicit local desktop action. It issues one GET to `https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json` with a positive user-supplied CIK, padded to ten digits. It does not infer ticker mappings, acquire credentials or connect to EDGAR filer/account APIs. `cancelSecRequest({requestId})` cancels this capability; script cancellation remains a separate method.

SEC documents the public `data.sec.gov` APIs as requiring no authentication or API keys. Its FAQ permits reuse of government-created and public filing content. Automated access requires a declared User-Agent and restrained request rate. OpenCandle declares `OpenCandle/0.8.0 (getopencandle.com; optional public SEC data reader)`, without inventing a person or contact address. SEC may still deny a request; OpenCandle reports that failure without a workaround. This declared identity is not proof that SEC accepts every request. Its example agent includes a contact address; no personal address is collected or automatically sent by OpenCandle.

Requests allow no redirects, renderer URLs/hosts/headers, cookies, authentication, referrer, persistent cookie jar, automatic retries or external shell links. Only one SEC request is active at a time, start spacing is at least one second, and upstream 403/429 responses suppress new requests for ten minutes. This is stricter than SEC's documented ten-requests-per-second ceiling but cannot control unrelated programs sharing an IP address. The request is capped at ten seconds and 32 MiB of streamed decoded bytes; Content-Length is only an additional early check. Wrong origin/type/status, invalid UTF-8/JSON, unsafe JSON, mismatched CIK or malformed known schema produces a bounded structured error. Cancellation/timeout resolves once, aborts transport and prevents later data delivery. No request occurs at app startup. Renderer networking remains denied.

The success envelope contains `{schemaVersion:1,cik,entityName,data,provenance}`. `data` retains the full accepted raw company-facts object, including taxonomy, concept, units, observations, period dates, values, form, accession, filing date, optional fiscal/frame metadata and unknown fields. Nullable/missing descriptive label metadata remains null/absent; it is not replaced with invented source labels. `provenance` states provider `SEC EDGAR`, kind `public-unauthenticated`, exact source URL, retrieval timestamp, body SHA-256, bytes and limited coverage. It contains no quote freshness assertion, as-known-at-time reconstruction or financial metric normalization. Raw retrieval is not stored on disk by this adapter; renderer local persistence remains separately explicit and bounded.

SEC aggregates non-custom, entity-wide XBRL concepts. It does not supply every custom/disaggregated filing fact, a market-price feed or a complete fundamental-ratio catalog. Normalization must select taxonomy/tag/unit/period/form/accession/filing date explicitly and preserve restatements. No automatic annualization, YTD subtraction, missing-quarter substitution or latest-restatement backfill is certified by this capability. SEC may correct or remove prior filings; retrieval time and filed date are distinct evidence.

Seven tests in `tests/security/public-sec.test.ts` use synthetic transport only: fixed-host/header boundary; raw field preservation/provenance; nullable metadata; redirect/origin/status/content/schema rejection; declared and actual byte limits; active/rate/backoff gates; cancel/timeout/no late result, including active-reader cancellation. Separately, bounded actual host-Node reads accepted Apple and GameStop public JSON after nullable metadata repairs. The final GameStop response normalizes to 510 concepts/23,663 observations while preserving unknown `fy`/`fp`. Only response metadata, counts and hashes were retained. This does not prove packaged Electron execution, native controls or reference financial-ratio parity; a provider error is never counted as a pass.
