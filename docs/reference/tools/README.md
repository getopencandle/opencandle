# Tool reference

This folder holds reference descriptions of how each OpenCandle tool is meant to work, written from the original sources where they exist (the author's book, paper or article) and checked against independent references. Each file says what the tool is for, how the author intended it to be used, how a user interacts with it, the exact calculation and when a signal becomes known, the standard defaults, and the known pitfalls. They are used to check the OpenCandle's behaviour and as the basis for the user guide.

Every file starts with a front matter block: id, name, kind, family, a list of sources (each marked primary or secondary), and an overall confidence rating. The body then uses the same headings in the same order: Purpose, How the author meant it to be used, How you interact with it, Calculation, Standard defaults, Reading it, Common mistakes and edge cases, and Open questions. Where a tool has no single author, the file says so and describes common practice instead.
